# Лицензионное соглашение AvtoVinchickTG

Версия: 1.0

Настоящее соглашение регулирует использование приложения AvtoVinchickTG.

1. Назначение

AvtoVinchickTG предназначен для локальной автоматизации обработки сообщений Telegram-бота Дайвинчик, фильтрации анкет и отправки уведомлений в Telegram-бота, указанного пользователем.

2. Условия использования

Пользователь использует приложение на свой риск и самостоятельно отвечает за соблюдение правил Telegram, правил сторонних ботов, законодательства своей страны и ограничений используемых прокси-сервисов.

3. Данные и учетные записи

Приложение хранит настройки и Telegram-сессию локально на устройстве пользователя. Разработчик приложения не получает доступ к Telegram-аккаунту, bot token, proxy, chat_id или содержимому сообщений, если пользователь сам не передает эти данные третьим лицам.

4. Ограничение ответственности

Приложение предоставляется "как есть", без гарантий бесперебойной работы, совместимости с будущими изменениями Telegram, Дайвинчика, Bot API или прокси-сервисов. Разработчик не несет ответственности за блокировки аккаунтов, потерю доступа, ошибки фильтрации, пропущенные сообщения, некорректные автоматические действия или любые прямые и косвенные убытки.

5. Запрещенное использование

Запрещается использовать приложение для спама, массового преследования пользователей, обхода ограничений платформ, сбора персональных данных без законного основания, мошенничества, угроз, шантажа или иных действий, нарушающих права других людей.

6. Обновления

Приложение может проверять наличие новой версии через GitHub Releases и устанавливать обновление только после действия пользователя в интерфейсе. Обновления могут менять поведение фильтров, интерфейс и способ взаимодействия с Telegram-ботом.

7. Принятие соглашения

Установка или запуск приложения означает принятие условий настоящего соглашения. Если пользователь не согласен с условиями, он обязан не устанавливать и не использовать приложение.
